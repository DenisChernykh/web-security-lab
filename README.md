# Web Security Lab

Интерактивная лаборатория веб-безопасности: сопоставление уязвимых реализаций с защищёнными вариантами.

## Возможности

- SQL injection, XSS, IDOR и CSRF.
- Изолированные сервисы в Docker Compose и единая веб-консоль.
- Воспроизводимые сценарии проверки атак и защиты.

## Инженерные акценты

- Понимание причин уязвимостей и способов их устранения.
- Разработка проверяемых сценариев безопасности.
- Изоляция окружения и сравнение поведения разных реализаций.

## Стек

TypeScript, Vite, Vitest.

## Навигация по коду

- [tests/](tests/) — автоматизированные проверки.
- [docs/](docs/) — архитектура и документация.

## Разработка

```sh
pnpm install
pnpm test
pnpm build
```
